# Sobre o Projeto

A **Spectra** é uma proposta de plataforma inteligente de segurança voltada para **aplicações web e APIs**, desenvolvida como projeto de Trabalho de Conclusão de Curso.

A plataforma tem como objetivo auxiliar na identificação de possíveis vulnerabilidades, análise de riscos e visualização dos resultados de segurança de maneira clara, organizada e acessível.

A proposta é transformar informações técnicas em uma experiência visual mais intuitiva, permitindo que desenvolvedores e empresas tenham uma visão mais clara sobre a segurança de suas aplicações.

O fluxo principal da plataforma é baseado em:

```text
ANALISAR → DETECTAR → PONTUAR → VISUALIZAR → ANALISAR NOVAMENTE
```

# Objetivo

O principal objetivo da **Spectra** é desenvolver uma solução capaz de auxiliar na análise e no monitoramento da segurança de aplicações web e APIs.

A plataforma deverá apresentar os resultados das análises por meio de um dashboard contendo:

* Security Score;
* Níveis de risco;
* Vulnerabilidades identificadas;
* Métricas de segurança;
* Gráficos;
* Indicadores de segurança;
* Informações organizadas para facilitar a interpretação.

A proposta busca tornar informações relacionadas à segurança mais compreensíveis, permitindo que os resultados sejam apresentados de maneira visual e organizada.

# Proposta da Plataforma

A Spectra será estruturada como uma plataforma de análise e monitoramento de segurança para **aplicações web e APIs**.

A proposta inicial do sistema é permitir que o usuário realize uma análise e receba informações organizadas sobre a segurança da aplicação.

Os resultados deverão ser apresentados visualmente por meio de um dashboard, permitindo visualizar diferentes indicadores de segurança.

---

# Fluxo da Spectra

O funcionamento da plataforma será baseado em um fluxo de análise contínua:

```text
┌─────────────┐
│   ANALISAR  │
└──────┬──────┘
       ↓
┌─────────────┐
│   DETECTAR  │
└──────┬──────┘
       ↓
┌─────────────┐
│   PONTUAR   │
└──────┬──────┘
       ↓
┌─────────────┐
│  VISUALIZAR │
└──────┬──────┘
       ↓
┌─────────────┐
│   ANALISAR  │
│  NOVAMENTE  │
└─────────────┘
```

## 1. Analisar

O usuário inicia uma análise de uma aplicação web ou API.

## 2. Detectar

A plataforma deverá identificar possíveis vulnerabilidades e riscos relacionados à aplicação analisada.

## 3. Pontuar

Os resultados deverão ser organizados por meio de indicadores e um **Security Score**.

## 4. Visualizar

As informações serão apresentadas em um dashboard com gráficos, métricas e indicadores.

## 5. Analisar Novamente

Após a correção dos problemas identificados, uma nova análise poderá ser realizada para acompanhar a evolução da segurança.
